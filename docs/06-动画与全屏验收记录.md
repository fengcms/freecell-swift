# 1.2 动画与全屏验收记录

版本1.2.0 / build 3；按后续七项反馈实现。

## 行为

- 收牌与双击自动移动显示完全不透明的牌面飞行，使用平滑的起停曲线；整组牌龙保持间距。批量收牌依次飞入基础堆，长序列总时长约3秒。
- 胜利时显示带过渡的提示栏，最后一段牌面飞行结束后，从四个基础堆喷出彩纸。
- 已胜利时，顶部“新局”和胜利提示的“再来一局”都直接发牌；未完成牌局仍保留原确认提示。指定牌局面板也不在胜利状态显示“清除当前进度”文案。
- Ctrl + Cmd + F通过NSWindow.toggleFullScreen进入和退出原生全屏，窗口配置为fullScreenPrimary；使用macOS的独立全屏空间。
- 暂存牌双击先尝试基础堆、非空工作列，再尝试空列；不再从一个暂存位移到另一个暂存位。工作列牌的原优先顺序保留。
- 牌桌移除列号、空当标题与基础堆花色文字，释放原文字占用的布局空间。空槽的淡花色符号和可访问性名称仍保留。

## 实现约束

FreeCellCore生成安全收牌的中间局面；GameSession一次性提交最终规则状态并保存，另外发送只用于显示的BoardAnimationRequest。FreeCellPresentation将相邻局面转换为逐牌飞行坐标和确定性的时间线；AppKit牌桌负责约60Hz播放与彩纸绘制。计时和存档不依赖动画完成回调。

动画期间牌桌不接受新移动。撤销、重开、新局、暂停、切换应用或调整窗口均可取消视觉播放，直接显示当前规则局面。减少动态效果时跳过飞牌和彩纸，保留静态胜利提示。胜利提示采用覆盖层，不改变牌桌尺寸，避免最后一段动画被窗口布局变化中断。

## 已验证

- Debug应用构建通过。
- Debug、Release均通过26组检查；新检查覆盖暂存牌不互换、逐张收牌序列顺序、动画采样边界与终点、窗口内飞行坐标，以及整组动画间距。
- 独立测试窗口中实际按Ctrl + Cmd + F：进入全屏时原生标题栏控件消失，再次按键后恢复正常窗口。
- 从真实有效存档复制胜利前局面到独立测试目录，执行收牌后显示52/52及胜利提示。
- 点击胜利提示的“再来一局”：直接变为0步、0/52的新牌局，没有确认弹窗。
- 截图确认牌桌没有列号及槽位标题，空位和牌面布局完整。
- 最终Release应用打包，并通过codesign --verify --deep --strict。

逐帧动画美术效果与不同刷新率显示器表现未作完整人工回归；当前已验证确定性的时间线、状态约束及关键原生界面行为。原正常存档只读，用于复制测试局面；验证过程写入独立目录。

## 复验

```sh
swift run FreeCellChecks
swift run -c release FreeCellChecks
./scripts/build-app.sh
codesign --verify --deep --strict build/FreeCell.app
```

若有已获胜的有效存档，可生成独立胜利前测试局面：

```sh
swift run FreeCellChecks --write-pre-win-fixture <源存档路径> build/pre-win-profile/game-v1.json
open -n build/FreeCell.app --args --verification --verification-directory "$PWD/build/pre-win-profile"
```

生成器保留原种子及合法历史，回退到最终批量收牌前；不会修改源文件。新版本仍使用schemaVersion 1和原存档路径。
