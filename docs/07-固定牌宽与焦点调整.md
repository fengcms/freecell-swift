# 固定牌宽与焦点调整（1.3.0）

## 行为

- 原图为 264 × 384，圆角半径按约 16 像素等比例缩放；牌面、底板、空位轮廓保持一致。
- 牌宽仅根据窗口宽高计算，预留至少十三张纸牌按常规间距叠放的空间。初始牌列下方留出伸展空间。
- 每列分别计算间距：常规间距为牌宽的 30%，空间不足时取该列可用高度除以叠放层数。牌列数量和长度不会改变牌宽。
- 绘制、命中测试、辅助功能区域使用同一列间距。拖拽牌龙沿用来源列间距，移动动画也使用固定牌宽。
- 不预设首个激活位置。点击空白牌桌或未选牌时的空位，会取消待处理点击、选牌与焦点；Esc 同样清除焦点。
- 焦点按纸牌身份重新定位，目标列发生变化后落到该列最后一张牌，包含拖动到空列的情况。键盘方向键仍可主动建立焦点。

## 验证

Debug 与 Release 的 27 组检查全部通过，最终应用已打包并通过签名验证。新增检查覆盖不同窗口尺寸、1/13/26/52 张列长的牌宽不变、列起点不变、其他列位置不变、底部预留空间以及极长列完整容纳。原有规则、历史、存档、拖拽几何与动画检查继续通过。

焦点逻辑通过代码路径检查；未对本版本执行完整的鼠标交互回归。
