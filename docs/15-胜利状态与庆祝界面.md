# 胜利状态与庆祝界面

当全部 52 张牌进入基础堆后，牌局进入已完成状态。此后牌桌不再接受选牌、拖动、自动移牌、收牌、撤销、重做或暂停，避免已结算的胜局被继续修改；胜局统计只结算一次。

胜利覆盖层位于牌桌中央，显示庆祝信息、步数与用时，并以大按钮提供“再来一局”。点击按钮后立即发新局，不弹出清除进度确认。胜利界面也接受空格键和右键作为同一操作；这两个输入只在游戏窗口处于胜利状态时处理。正常游戏中，空格仍由牌桌键盘操作使用，右键行为仍由自动移牌设置控制。

界面文案覆盖英语、简体中文、繁体中文、法语、德语、西班牙语、阿拉伯语、日语和韩语。系统减少动态效果或用户关闭动画时，庆祝层仍可见，过渡动画会遵循设置。

## 验收

- `swift build`：通过。
- `swift run FreeCellChecks` 与 Release 打包：发布前执行。
- 翻译 JSON 解析及新增胜利提示九语言字段检查：通过。
- 实际试玩重点检查：胜利后右击基础堆牌不再取回；空格、右键及按钮都能开始新局；普通牌局中的空格和右击不受胜利快捷键影响。

输入监视器限定在当前游戏窗口，离开胜利状态后随覆盖层移除。代码实现位于 `VictoryCelebrationView.swift`、`VictoryInputMonitor.swift`、`GameView.swift` 和 `GameSession.swift`。
