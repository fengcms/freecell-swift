# 游戏统计开发与验收记录

状态：已实现，等待实际试玩反馈。对应完整产品口径见 [游戏统计产品设计方案](13-游戏统计产品设计方案.md)。

## 实现范围

统计通过工具栏按钮和“牌局 → 统计…”菜单打开独立可调整窗口，快捷键为 `⇧⌘S`。统计窗口包含总览、对局、牌局纪录和趋势四页。历史提供结果、无辅助、日期范围筛选、精确编号搜索、分页加载、详情和重新挑战；牌局纪录按洗牌版本和种子分组，支持挑战次数、最近挑战和编号排序；趋势展示最近八周或十二个月的胜局/放弃、胜率、时间及表格数据。

总览包括开始局数、胜率、胜局、放弃、未结算、连胜、最佳与平均成绩、累计时间、活跃天数和辅助操作计数。普通纪录与无辅助纪录可切换。无辅助资格按产品方案的自动收牌、重开、提示、撤销/重做、自动移牌、手动收牌和基础堆取回条件计算；失败原因保存在对应牌局中。

统计数据存放在 Application Support 下独立的 `statistics-v1.json`。牌局存档新增可选统计身份和重置排除标记；缺少统计身份的旧存档只从升级后的首次有效操作开始登记，并标记操作历史未知。计时按本地日期与时区保存片段；统计写入使用原子替换，定时、暂停、失活、重开与退出时刷新。胜局、放弃和尝试都用独立牌局 ID 管理，胜局重复结算会被忽略。

导入先在后台读取并校验 JSON，提供合并、替换与取消；合并按记录 ID 去重并拒绝冲突，外部进行中牌局只作为未结算统计记录。导出使用系统保存面板。重置和替换保留当前游戏及设置，并持久标记当前牌局从新统计周期排除；后续新局或重开重新登记。重置/替换确认以取消为回车默认操作，支持 Esc 和 ⌘C 取消。

所有新增界面文案已覆盖英语、简体中文、繁体中文、法语、德语、西班牙语、阿拉伯语、日语和韩语；统计窗口沿用应用 RTL 布局和动态语言刷新。

## 检查结果

- `swift build`：通过。
- 翻译目录 JSON 结构检查：九种 locale 字段齐全，统计窗口静态文案都有对应键。
- 尚需在实际牌局中试玩生命周期边界、导入冲突提示、重置确认按键和阿拉伯语窗口布局。统计不追溯升级前的胜局，这是数据模型的明确限制，不是漏记。

## 数据边界

统计文件不包含牌面、完整局面、移动历史、偏好、用户名或路径。JSON 导入不恢复游戏；错误或超限文件整份拒绝。若统计文件损坏，保留原文件并暂停统计写入，游戏仍可继续。历史记录按原始本地日期显示和汇总，不随着后来修改系统时区重新分桶。
