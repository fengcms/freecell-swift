# 1.6.0 多语言支持

支持英语、简体中文、繁体中文、法语、德语、西班牙语、阿拉伯语、日语、韩语。

## 选择与回退

通过 ⌘, 或菜单打开设置，在“界面 → 语言”选择。默认“跟随系统”，按系统的首选语言匹配；不受支持或没有首选语言时使用英语。法语、德语等区域变体匹配基础语言；中文优先识别 Hans/Hant，未指定文字时将台湾、香港、澳门匹配繁体，其他中文区域匹配简体。手动选择立即生效并保留到下次启动。

只在应用独立偏好中存储语言，不修改 macOS 全局语言，不改变牌局编号、历史、存档格式或规则。旧偏好文件缺少语言时采用“跟随系统”；未知语言值也回退到该设置。

## 覆盖范围

主界面、功能按钮、菜单、设置、规则、关于游戏、确认框、胜利/暂停信息、恢复与保存错误、操作提示和 VoiceOver 牌名与位置均本地化。作者姓名与中文个人签名作为原文保留，第三方作者及许可名称不翻译。macOS 管理的系统服务、窗口控制辅助说明、输入法等界面仍由系统语言决定。

阿拉伯语设置及界面文字使用从右向左的布局；牌桌保留从左至右的列顺序与键盘方向映射，纸牌图像、牌局编号及快捷键不镜像。较长工具栏文字在窄窗口自动换为两行；规则面板可滚动阅读，设置使用标准 Form 的滚动行为。牌桌仍无滚动条。

## 工程与验证

- `GameLanguage` 负责纯函数语言匹配，可独立测试。
- `GameLocalization` 在主线程管理运行时语言，读取随应用打包的 `Translations.json`，未找到目标译文时回退英语。
- 状态和规则错误在界面边界翻译，核心模型及已有存档保持兼容。
- 翻译使用 `%@` 参数，验证九种语言的覆盖和占位符数量，保留数字及编号。
- 自定义菜单响应观察到的语言变化；系统常用菜单标题在 AppKit 菜单刷新后重新本地化。

验证命令：

```sh
swift run FreeCellChecks
swift run -c release FreeCellChecks
./scripts/check-localization.sh
./scripts/build-app.sh
codesign --verify --deep --strict build/FreeCell.app
```

独立语言界面验证示例（不写正常存档或偏好）：

```sh
open -n build/FreeCell.app --args --verification \
  --verification-directory /tmp/FreeCell-Language-QA \
  --verification-language ar --verification-silent
```

语言解析与旧偏好兼容检查加入原规则验证目标，共 30 组。运行时翻译检查覆盖全部九种语言及动态牌名、位置、容量、提示和计数格式。界面验收使用独立实例，已逐项切换全部九种语言，检查德语规则、阿拉伯语布局、英语确认与关于窗口，以及重启后的语言保留。翻译未经过各语言母语者审校。
